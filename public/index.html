The Manifesto

  • Developer experience first — the first five minutes produce working code.
  • Progressive disclosure — easy things stay easy, advanced things are possible.
  • The type system is a guide — autocomplete-driven discovery, misuse is a build error.
  • Errors and visibility are values — never panicked, never swallowed.
  • Conventions over invention — stdlib shapes, RFCs, and OTel, not package-specific dialects.
